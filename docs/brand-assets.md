# Brand assets

The MISP DLM visual identity distinguishes this independent lifecycle-manager project from the upstream MISP project. The selected repository assets are intentionally small: one README lockup pair, one documentation mark, one favicon, and one social-preview image.

## Rendering rules

- Use the supplied assets without recoloring, cropping, rotating, or distortion.
- Scale proportionally.
- Keep at least one quarter of the bracket height as clear space.
- Use the light-ink lockup on dark surfaces and the dark-ink `-light` lockup on light surfaces.
- Do not use both the lockup and banner together as a page hero.
- Do not use the upstream MISP logo to identify this independent project.
